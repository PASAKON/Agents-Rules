# HOME — เทส vault รวม 3 wiki

ไฟล์นี้เป็นไฟล์เดียวที่เกิดใหม่ ไม่ได้แตะ repo ไหนเลย
อีก 3 โฟลเดอร์เป็น symlink ชี้ไป repo จริง

## จุดประสงค์ของการเทส

พิสูจน์ว่า Obsidian มองทะลุ symlink ได้ไหม และลิงก์ข้าม repo ทำงานจริงไหม
ถ้าได้ผล กราฟจะขึ้นเส้นจากไฟล์นี้ไปหาโน้ตทั้ง 3 wiki ด้านล่าง

## ลิงก์ทดสอบ ข้ามไปทั้ง 3 repo

- [[CLAUDE]]
- [[CONTRIBUTING]]
- [[DEV-PROMPT]]

**ไปที่ MoonieX-Wikis (110 โน้ต)**
- [[INDEX]]
- [[IRON-RULES]]
- [[CHEATSHEET]]

**ไปที่ LungNote-wikis (42 โน้ต)**

- [[Rich-Menu-Install]]

## สิ่งที่ต้องดูตอนเปิด Obsidian

1. แถบซ้ายเห็น 3 โฟลเดอร์ agents, mooniex, lungnote ไหม
2. เปิดมุมมองกราฟ นับจุดได้ราว 204 จุดไหม ถ้าเห็นแค่จุดเดียวคือ symlink ไม่ผ่าน
3. ลิงก์ข้างบนเป็นสีปกติ ไม่ใช่สีจาง แปลว่าเจอไฟล์ปลายทางจริง
4. กราฟลากเส้นจาก HOME ไปทั้ง 3 กลุ่มไหม

## ผลเทสฝั่งเครื่องมือค้นหา ทำไปแล้ว

| เครื่องมือ | ผ่าน symlink |
|---|---|
| find -L | 204 ไฟล์ ผ่าน |
| rg --follow | 204 ไฟล์ ผ่าน |
| find ปกติ | 0 ไฟล์ ไม่ผ่าน |
| rg ปกติ | 0 ไฟล์ ไม่ผ่าน |
| grep -r | 0 ไฟล์ ไม่ผ่าน |

สรุปฝั่งเครื่องมือ: agent ต้องค้นที่ path repo จริงเท่านั้น ห้ามชี้มาที่ vault นี้
เพราะจะได้ผลลัพธ์ศูนย์แบบเงียบ ไม่มี error เตือน

## ลบทิ้งยังไงถ้าไม่เอา

ลบทั้งโฟลเดอร์ `Wiki-Vault-TEST` ได้เลย ไฟล์จริงใน repo ทั้ง 3 ไม่หายไปไหน
เพราะข้างในเป็นแค่ทางลัด ไม่ใช่ตัวไฟล์
